# OIBSIP - Oasis Infobyte Internship Projects

This repository contains all tasks completed during the Oasis Infobyte Internship using Java, Eclipse, and MySQL.

## Projects Included
1. Online Reservation System
2. Online Examination System
3. Number Guessing Game
4. Digital Library Management System

## Technologies Used
- Java
- Eclipse IDE
- MySQL
- JDBC
- HTML, CSS (where applicable)

## How to Run
1. Import project into Eclipse
2. Configure MySQL database
3. Update DB credentials in code
4. Run the main class / server
